# 집계함수와 GROUP BY (COUNT, SUM, AVG, MAX, MIN, HAVING)

> 🔥 **매회 출제** (priority 3)

![[db-sql-004.svg]]

## 🌱 왜 배우나

학생 500명의 성적표를 한 장씩 보는 것과 "학과별 평균 점수"를 한눈에 보는 것은 전혀 다른 일이다. 선생님이나 경영진이 원하는 건 보통 후자, 즉 요약된 숫자다. 집계함수(Aggregate Function, 여러 행을 하나의 값으로 요약하는 함수)와 GROUP BY(묶기)가 없다면 전체 데이터를 엑셀로 내려받아 손으로 평균을 계산해야 할 것이다. 카페에서 "오늘 매출 총액과 메뉴별 판매량"을 알고 싶은데 영수증 수백 장을 일일이 세는 꼴이다. 데이터베이스는 이 요약을 한 줄 쿼리로 해주지만, NULL(값 없음)이 섞이거나 WHERE와 HAVING을 헷갈리면 결과가 틀어지므로 그 규칙을 정확히 알아야 한다.

## 📖 핵심 개념

집계함수(Aggregate Function)는 여러 행의 값을 모아 하나의 결과값으로 요약하는 함수다. 대표적으로 COUNT(개수), SUM(합계), AVG(평균), MAX(최대), MIN(최소)이 있다. 중요한 것은 NULL(값 없음) 처리 규칙이 함수마다 다르다는 점이며, 이 차이가 매회 출제된다. GROUP BY 절과 함께 쓰면 특정 열의 값이 같은 행끼리 묶어서 그룹별로 집계할 수 있다. 그룹화된 결과에 조건을 걸 때는 WHERE가 아니라 HAVING을 써야 한다. WHERE는 그룹화 이전에 행을 거르고, HAVING은 그룹화 이후에 집계 결과를 거른다.

## 🔍 시각화

```
원본 데이터 (학생 표):
┌──────┬──────┐
│ 학과 │ 점수 │
├──────┼──────┤
│ 컴공 │  80  │
│ 컴공 │ NULL │
│ 경영 │  70  │
│ 경영 │  90  │
│ 경영 │  60  │
└──────┴──────┘

GROUP BY 학과 → 집계함수 적용:
┌──────┬───────────┬───────────┬──────────┐
│ 학과 │ COUNT(*)  │COUNT(점수)│AVG(점수) │
├──────┼───────────┼───────────┼──────────┤
│ 컴공 │    2      │    1      │   80     │ ← NULL 제외
│ 경영 │    3      │    3      │   73.3   │
└──────┴───────────┴───────────┴──────────┘

WHERE vs HAVING 적용 시점:
FROM → WHERE(행 필터) → GROUP BY → 집계함수 → HAVING(그룹 필터) → SELECT
```

## ↔️ 이웃 개념 구분

- **COUNT(\*) vs COUNT(열 이름)**: COUNT(\*)는 NULL을 포함한 전체 행 수, COUNT(열 이름)은 해당 열에서 NULL을 제외한 행 수. 가장 자주 출제되는 차이.
- **WHERE vs HAVING**: WHERE는 그룹으로 묶기 전에 개별 행을 거르고, HAVING은 그룹으로 묶은 후 집계 결과를 거른다. WHERE 절에서는 집계함수를 쓸 수 없다.

**핵심 용어**

- **COUNT(\*)**: NULL을 포함한 전체 행 수를 반환한다.
- **COUNT(열 이름)**: 해당 열에서 NULL을 제외한 행 수를 반환한다.
- **SUM / AVG / MAX / MIN**: 모두 NULL을 자동으로 제외하고 계산한다. AVG(평균)는 NULL을 뺀 행 수로 나눈다(0으로 치지 않는다).
- **GROUP BY**: 지정한 열의 값이 같은 행끼리 묶어 집계한다. SELECT에는 GROUP BY에 쓴 열 또는 집계함수만 올 수 있다.
- **HAVING**: GROUP BY로 묶은 뒤 집계 결과에 조건을 건다. WHERE와 달리 집계함수를 조건에 쓸 수 있다.
- **실행 순서**: FROM → WHERE → GROUP BY → 집계함수 적용 → HAVING → SELECT → ORDER BY.

## ✅ 스스로 가르쳐보기

**질문**: 점수 열에 `80, NULL, 70, NULL, 90`이 있을 때, COUNT(\*), COUNT(점수), AVG(점수) 각각의 결과가 얼마이고 왜 그런지 친구에게 설명해 보라.

체크포인트:
- [ ] COUNT(\*)와 COUNT(열)의 NULL 처리 차이를 정확히 말했는가?
- [ ] AVG가 NULL을 0이 아니라 "없는 행"으로 처리하는 이유를 설명했는가?
- [ ] WHERE와 HAVING이 각각 언제 적용되는지 실행 순서로 설명했는가?

## 🎯 시험 응용

> **2025-3회**: COUNT(*)와 COUNT(컬럼명)의 NULL 처리 차이 문제 출제. AVG 계산 시 NULL이 포함된 경우 분모가 달라지는 함정 주의. HAVING 절에서 집계함수를 조건으로 쓸 수 있지만 WHERE 절에서는 불가능하다는 점도 빈출 포인트.

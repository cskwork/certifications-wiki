# Java 재귀함수

> 🔥 **매회 출제** (priority 3)

![[pg-language-013.svg]]

## 🌱 왜 배우나

숫자 1234를 뒤집어 4321로 만들거나, 폴더 안의 폴더를 끝까지 뒤지거나, 트리 구조를 탐색하는 작업은 "같은 작업을 한 단계 작은 입력에 반복"하는 성격이다. 반복문으로도 쓸 수 있지만 코드가 길고 상태 변수를 수동 관리해야 한다. 재귀는 마트료시카 인형처럼 "한 층만 벗기고 나머지는 더 작은 나에게 맡긴다"는 선언이다. 문제를 자기 자신의 축소판으로 기술할 수 있을 때, 반복문보다 훨씬 짧고 의도가 선명한 코드를 쓰려고 재귀 호출이 언어 기능으로 제공된다.

## 📖 핵심 개념

Java에서 재귀함수는 C와 동일한 원리로 동작하지만, Java 특유의 **메서드 오버라이딩과 결합된 재귀**, **static 메서드 재귀** 등이 출제된다. 호출 스택을 추적할 때 매개변수 값의 변화를 단계별로 기록하는 것이 핵심이다.

**핵심 용어**

- **재귀 호출**: 메서드가 자기 자신을 호출. `static` 메서드에서 주로 출제
- **종료 조건**: `if (n <= 0) return;` 등으로 무한 호출 방지
- **호출 트리**: 재귀 호출 관계를 트리로 시각화하면 추적이 쉬움
- **스택 오버플로우**: 종료 조건 없이 재귀 시 StackOverflowError 발생

## ✅ 이해 확인

1. 다음 `forward(3)`의 출력 결과는?
   ```java
   static void forward(int n) {
       if (n <= 0) return;
       System.out.print(n + " ");
       forward(n - 1);
   }
   ```
   <details><summary>정답</summary>`3 2 1 `. 출력이 **재귀 호출 전**에 있으므로 값을 먼저 찍고 재귀로 들어가서 순방향으로 출력된다.</details>
2. 위 코드에서 `System.out.print(n + " ");`를 `forward(n - 1);` **다음** 줄로 옮기면 결과는?
   <details><summary>정답</summary>`1 2 3 `. 출력이 재귀 호출 **뒤**에 오면 가장 깊은 호출(f(1))이 먼저 출력되고 복귀하며 역순으로 찍힌다. 출력 위치가 출력 순서를 완전히 뒤집는다.</details>
3. `A obj = new B();`에서 A의 재귀 메서드 `f()`가 내부에서 `f(n-1)`을 호출할 때, 실제로는 A와 B 중 어느 쪽의 f가 재호출되는가?
   <details><summary>정답</summary>B의 f가 호출된다. 인스턴스 메서드는 동적 바인딩되므로, A의 f 안에서 `this.f(n-1)`을 호출해도 실제 객체 타입인 B의 오버라이딩된 f로 다시 들어간다. 재귀 + 오버라이딩 혼합 문제의 핵심.</details>

## 🎯 시험 응용

> - **2025-1회**: Java 재귀 메서드 결과 추적 (답: 20). 종료 조건과 반환값 계산이 핵심 > - **2024-2회**: 재귀 + 오버라이딩 혼합. 동적 바인딩으로 어느 클래스의 재귀가 호출되는지 판단 > - **출제 패턴**: `f(n-1)` 형태의 재귀 호출 후 반환값 조합. 출력 위치(전/후)로 순서 결정 > - **트레이싱 팁**: 매개변수 → 조건 체크 → 재귀 호출 → 반환값 순서로 표 작성

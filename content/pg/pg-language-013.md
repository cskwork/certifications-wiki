# Java 재귀함수

> 🔥 **매회 출제** (priority 3)

![[pg-language-013.svg]]

## 🌱 왜 배우나

어떤 문제는 "큰 문제를 같은 모양의 작은 문제로 쪼개는 것"으로 풀 수 있다. 예를 들어 숫자 1234를 뒤집어 4321로 만들려면, 끝자리(4)를 떼어내고 나머지(123)를 또 같은 방식으로 뒤집으면 된다. 이처럼 함수(특정 작업을 묶은 코드 덩어리)가 자기 자신을 다시 호출하는 것을 재귀(recursion)라고 한다. 마트료시카 인형처럼 큰 인형을 열면 같은 모양의 작은 인형이 나오고, 또 열면 더 작은 인형이 나오다가 마지막 인형에서 멈추는 것과 같다. 이 "마지막 인형"이 종료 조건(base case)이고, 이것이 없으면 무한히 호출되다 프로그램이 멈춘다(스택 오버플로우).

## 📖 핵심 개념

재귀함수(recursive function)란 자기 자신을 호출하는 함수다. 반드시 두 가지가 있어야 한다. 첫째, 종료 조건(base case)으로 "더 이상 쪼갤 수 없을 때 멈추는 규칙"이다. 둘째, 재귀 단계(recursive step)로 "문제를 한 단계 줄여서 자기 자신을 다시 부르는 부분"이다. 호출이 일어날 때마다 컴퓨터는 호출 스택(call stack, 함수 호출 정보를 쌓아두는 메모리 공간)에 정보를 쌓는다. 종료 조건에 도달하면 쌓였던 호출이 역순으로 하나씩 돌아오며(되감기) 결과를 조합한다. 재귀 호출 "전"에 출력하면 순방향(큰→작은), "후"에 출력하면 역방향(작은→큰) 순서가 된다.

## 🔍 시각화

```
┌─────────── f(1234) 호출 흐름 ──────────────┐
│                                            │
│  f(1234)                                   │
│  ├─ 출력: 1234 % 10 = 4                    │
│  └─ f(123) 호출                            │
│     ├─ 출력: 123 % 10 = 3                  │
│     └─ f(12) 호출                          │
│        ├─ 출력: 12 % 10 = 2                │
│        └─ f(1) 호출                        │
│           ├─ 출력: 1 % 10 = 1              │
│           └─ f(0) 호출                     │
│              └─ 종료 조건: return           │
│                                            │
│  최종 출력: 4 3 2 1                         │
└────────────────────────────────────────────┘

┌─── 출력 위치에 따른 순서 차이 ─────────────┐
│                                            │
│  출력 → 재귀호출  (순방향)                  │
│  print(3), print(2), print(1)  → "3 2 1"  │
│                                            │
│  재귀호출 → 출력  (역방향)                  │
│  print(1), print(2), print(3)  → "1 2 3"  │
└────────────────────────────────────────────┘
```

## ↔️ 이웃 개념 구분

- **재귀 vs 반복문**: 재귀는 함수가 자기 자신을 호출하고, 반복문(for, while)은 같은 코드 블록을 조건이 참인 동안 반복한다. 같은 결과를 낼 수 있지만, 재귀는 코드가 짧고 의도가 명확한 대신 호출 스택 메모리를 더 쓴다.
- **종료 조건 vs 반복 조건**: 재귀의 종료 조건은 "멈추는 시점"을 정하고, 반복문의 조건은 "계속 도는 시점"을 정한다. 방향이 반대다.

**핵심 용어**

- **재귀 호출(recursion)**: 함수가 자기 자신을 다시 부르는 것
- **종료 조건(base case)**: 재귀를 멈추는 조건. `if (n <= 0) return;` 등
- **호출 스택(call stack)**: 함수 호출 정보를 순서대로 쌓아두는 메모리 공간. 재귀마다 한 층씩 쌓임
- **스택 오버플로우(StackOverflowError)**: 종료 조건 없이 재귀가 무한 반복될 때 스택이 넘쳐서 발생하는 오류

체크포인트:
- [ ] 재귀 호출 전 출력이 왜 순방향(3→2→1)인지 설명했는가
- [ ] 재귀 호출 후 출력이 왜 역방향(1→2→3)인지 설명했는가
- [ ] 호출 스택이 쌓였다가 되돌아오는 과정을 언급했는가
- [ ] 종료 조건이 없으면 어떻게 되는지 말했는가

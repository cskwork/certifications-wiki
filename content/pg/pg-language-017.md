# Python 문자열 메서드

> 🔥 **매회 출제** (priority 3)

![[pg-language-017.svg]]

## 🌱 왜 배우나

프로그램에서 문자열(글자들의 나열)을 가공하는 일은 아주 흔하다. "apple,banana,cherry" 같은 데이터를 쉼표 기준으로 나누거나, 사용자가 입력한 "  홍길동  "에서 양쪽 빈칸을 지우거나, 문서 속 "구버전"을 "신버전"으로 바꾸는 작업이 그렇다. 이걸 직접 반복문(같은 코드를 되풀이하는 구문)으로 쓰면 코드가 길고 실수가 잦다. Python은 자주 쓰는 문자열 조작을 메서드(기능)로 미리 만들어 두었다. `split()`은 가위처럼 자르기, `join()`은 풀처럼 이어 붙이기, `replace()`는 지우개+펜처럼 바꾸기, `strip()`은 양쪽 빈칸 털기다. 또 Python 문자열은 불변(immutable)이라, 메서드를 호출해도 원본은 바뀌지 않고 항상 새로운 문자열이 만들어진다.

## 📖 핵심 개념

Python 문자열은 불변(immutable, 한번 만들어지면 내용을 바꿀 수 없음)이다. 따라서 모든 문자열 메서드는 원본을 건드리지 않고 새 문자열(또는 리스트)을 만들어서 돌려준다. 가장 자주 출제되는 세 메서드는 `split()`(문자열 → 리스트로 분리), `join()`(리스트 → 문자열로 합치기), `replace()`(특정 부분을 다른 글자로 교체)다. split의 반환 타입은 리스트(list, 여러 값을 순서대로 담는 자료구조)이고, join의 반환 타입은 문자열(str)이다. replace는 매칭되는 모든 부분을 교체한다(첫 번째만이 아님). 이 메서드들을 연속으로 호출하는 체인(chain) 형태가 시험에 자주 나온다.

## 🔍 시각화

```
┌─ split → join → replace 체인 흐름 ────────────────────┐
│                                                       │
│  "apple,banana,cherry"                                │
│         │                                             │
│         ▼  split(",")                                 │
│  ['apple', 'banana', 'cherry']   ← 리스트(list)       │
│         │                                             │
│         ▼  "-".join(...)                              │
│  "apple-banana-cherry"           ← 문자열(str)        │
│         │                                             │
│         ▼  replace("banana", "grape")                 │
│  "apple-grape-cherry"            ← 새 문자열(str)     │
└───────────────────────────────────────────────────────┘

┌─ join 호출 방식 주의 ─────────────────────────────────┐
│                                                       │
│   ✗  리스트.join(구분자)    ← 틀린 방식               │
│   ✓  구분자.join(리스트)    ← 올바른 방식             │
│                                                       │
│   "-".join(['a','b','c'])  →  "a-b-c"                 │
└───────────────────────────────────────────────────────┘
```

## ↔️ 이웃 개념 구분

- **split vs join**: `split()`은 하나의 문자열을 구분자 기준으로 잘라서 리스트로 만들고, `join()`은 리스트의 요소들을 구분자로 이어붙여 하나의 문자열로 만든다. 서로 반대 방향의 작업이다.
- **find vs index**: 둘 다 문자열 속에서 특정 글자의 위치를 찾지만, 찾는 글자가 없을 때 `find()`는 -1을 반환하고 `index()`는 에러(ValueError)를 발생시킨다.

**핵심 용어**

- **split(구분자)**: 구분자(separator) 기준으로 문자열을 잘라 리스트(list)로 반환. `"a,b,c".split(",")` → `['a','b','c']`
- **join(리스트)**: 리스트의 요소들을 구분자로 이어 붙여 하나의 문자열로 반환. `"-".join(['a','b'])` → `"a-b"`
- **replace(old, new)**: 모든 old를 new로 치환한 새 문자열 반환. `"aab".replace("a","x")` → `"xxb"`
- **find(str)**: str이 처음 나타나는 인덱스(위치 번호, 0부터 시작)를 반환. 없으면 -1
- **upper() / lower()**: 모든 글자를 대문자/소문자로 변환한 새 문자열 반환
- **strip()**: 양쪽 공백(빈칸, 탭, 줄바꿈)을 제거한 새 문자열 반환. `lstrip()`은 왼쪽만, `rstrip()`은 오른쪽만
- **count(str)**: 문자열 안에서 str이 몇 번 나타나는지 횟수 반환
- **startswith(str) / endswith(str)**: 문자열이 str로 시작/끝나는지 True 또는 False 반환
- **불변(immutable)**: 한번 만들어진 문자열의 내용을 바꿀 수 없는 성질. 메서드는 항상 새 문자열을 만듦

## ✅ 스스로 가르쳐보기

> 친구에게 `"apple,banana,cherry"`를 `split(",")`으로 자른 뒤, `"-".join()`으로 다시 합치는 과정을 단계별로 설명해 보세요. 각 단계에서 반환되는 값의 타입(리스트인지 문자열인지)까지 말할 수 있어야 합니다.

체크포인트:
- [ ] split의 반환 타입이 리스트(list)임을 말했는가
- [ ] join의 호출 주체가 구분자 문자열이라는 점을 설명했는가
- [ ] join의 반환 타입이 문자열(str)임을 말했는가
- [ ] replace가 첫 번째만이 아니라 모든 매칭을 바꾼다는 점을 언급했는가

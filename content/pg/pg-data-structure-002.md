# 연결 리스트

> 🔥 **매회 출제** (priority 3)

![[pg-data-structure-002.svg]]

## 🌱 왜 배우나

배열(데이터를 한 줄로 나란히 저장하는 방법)은 크기가 처음에 정해져 있다. 중간에 새 값을 끼워 넣으려면 뒤쪽 데이터를 하나씩 전부 밀어내야 한다. 마치 꽉 찬 줄서기 맨 앞에 한 명을 넣으려고 뒤에 선 모든 사람이 한 칸씩 움직이는 것과 같다.

연결 리스트는 이 문제를 해결하기 위해 등장했다. "각 데이터에 '다음 데이터는 여기에 있어요'라는 쪽지를 붙여 두자"는 아이디어다. 데이터가 메모리(컴퓨터 안에서 값이 저장되는 공간) 여기저기에 흩어져 있어도, 쪽지만 따라가면 순서대로 읽을 수 있다. 새 데이터를 끼워 넣을 때는 쪽지 두 장만 고쳐 쓰면 끝이다.

## 📖 핵심 개념

연결 리스트(Linked List)는 노드(데이터를 담는 한 칸)들을 포인터(다음 칸의 위치를 알려주는 주소)로 연결한 자료구조(데이터를 정리해서 저장하는 방식)다. 배열과 달리 메모리가 연속적이지 않아도 된다. 삽입·삭제는 연결 쪽지(포인터)만 바꾸면 되므로 O(1, 상수 시간 — 데이터가 아무리 많아도 걸리는 시간이 같다)이다. 반면, 특정 위치를 바로 찾아가는 것은 처음부터 하나씩 따라가야 하므로 O(n, 데이터 개수에 비례하는 시간)이 걸린다. 시험에서는 주로 C 구조체(여러 값을 묶어 하나로 다루는 사용자 정의 타입)와 포인터를 이용한 코드를 주고, 순회(처음부터 끝까지 차례로 방문하기) 결과를 추적하는 형식으로 출제된다.

## 🔍 시각화

```
단일 연결 리스트 구조:

head
  │
  ▼
┌──────┐    ┌──────┐    ┌──────┐    ┌──────┐
│ 데이터│    │ 데이터│    │ 데이터│    │ 데이터│
│  35  │    │  42  │    │  11  │    │  21  │
├──────┤    ├──────┤    ├──────┤    ├──────┤
│ next ─┼───▶│ next ─┼───▶│ next ─┼───▶│ next ─┼───▶ NULL
└──────┘    └──────┘    └──────┘    └──────┘
  노드1       노드2       노드3       노드4

맨 앞에 새 노드 삽입:

  ┌──────┐
  │  새  │
  │  5   │
  ├──────┤
  │ next ─┼──┐
  └──────┘  │    head 가 여기를 가리키도록 변경
            ▼
         기존 노드1 → 노드2 → ...
```

## ↔️ 이웃 개념 구분

- **배열 vs 연결 리스트**: 배열은 번호로 바로 접근 가능(빠른 조회), 연결 리스트는 쪽지를 따라가야 해서 조회는 느리지만 삽입·삭제가 빠르다.
- **단일 연결 리스트 vs 이중 연결 리스트**: 단일은 앞→뒤 한 방향으로만, 이중은 앞↔뒤 양방향으로 이동 가능.

**핵심 용어**

- **노드(Node)**: 데이터 한 칸. 값(data)과 다음 노드의 위치(next 포인터)를 함께 담고 있다
- **head**: 연결 리스트의 시작점. 첫 번째 노드를 가리키는 포인터
- **->**: 포인터를 통해 구조체 안의 값에 접근하는 연산자. `p->data`는 `(*p).data`와 같은 뜻
- **단일 연결 리스트(Singly Linked List)**: 한 방향(next)으로만 이동 가능한 연결 리스트
- **이중 연결 리스트(Doubly Linked List)**: prev(이전)와 next(다음) 양방향으로 이동 가능
- **원형 연결 리스트(Circular Linked List)**: 마지막 노드의 next가 다시 첫 노드(head)를 가리켜 원형으로 연결된 구조

## ✅ 스스로 가르쳐보기

이 내용을 처음 듣는 친구에게 설명한다고 생각하고, 본인만의 비유로 **연결 리스트**를 한 문장으로 정의해보세요.

**체크포인트** — 아래 항목을 스스로 설명할 수 있는지 확인하세요:
- 배열과 연결 리스트의 삽입·삭제 속도 차이가 왜 생기는지
- `p = p->next`가 포인터를 따라간다는 말이 구체적으로 무슨 뜻인지
- 맨 앞에 삽입할 때 `newNode->next = head`를 먼저 해야 하는 이유
- 순회가 NULL에서 멈추는 이유

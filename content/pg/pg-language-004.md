# Python 핵심 문법

> 🔥 **매회 출제** (priority 3)

![[pg-language-004.svg]]

## 🌱 왜 배우나

리스트에서 "3번째부터 7번째까지만 꺼내고 싶다"거나 "짝수 항목만 골라 새 리스트를 만들고 싶다"는 요구는 프로그래밍에서 너무 흔하다. 이를 매번 for문으로 쓰면 코드가 지저분해지고 실수도 잦다. 마치 긴 두루마리에서 원하는 구간만 가위로 오려 내거나, 체로 원하는 알갱이만 거르는 작업이다. Python은 이런 일을 한 줄로 표현하는 슬라이싱 `[start:end:step]`과 컴프리헨션 `{k: v for ... if ...}`을 언어 차원에서 제공해 코드를 짧고 읽기 쉽게 만들려고 이 문법을 도입했다.

## 📖 핵심 개념

Python의 슬라이싱, 딕셔너리, 컴프리헨션은 정보처리기사 실기에서 매회 1~2문항 출제되는 핵심 주제다. 슬라이싱은 `[start:end:step]` 형식으로 원본을 변경하지 않고 새 객체를 반환한다. 딕셔너리 컴프리헨션과 집합 연산(&, |, -)은 코드 추적 문제의 핵심 포인트다.

**핵심 용어**

- **슬라이싱 `[start:end:step]`**: end 인덱스는 미포함. `[::-1]`은 역순
- **dict.keys()**: 키 목록 반환 (dict_keys 타입)
- **dict.values()**: 값 목록 반환
- **dict.items()**: (키, 값) 튜플 쌍 반환
- **리스트 컴프리헨션**: `[표현식 for 변수 in 반복가능 if 조건]`
- **딕셔너리 컴프리헨션**: `{k: v for k, v in ...}`
- **집합 연산**: `&` 교집합, `|` 합집합, `-` 차집합

## ✅ 이해 확인

1. `"abcdefg"[2:5]`의 결과는? end 인덱스는 포함되는가?
   <details><summary>정답</summary>`'cde'`. 슬라이싱의 end 인덱스는 **미포함**이므로 인덱스 2,3,4만 포함된다.</details>
2. `a = {1,2,3,4}`, `b = {3,4,5,6}`일 때 `a & b`, `a | b`, `a - b`는 각각?
   <details><summary>정답</summary>`a & b` = `{3, 4}` 교집합, `a | b` = `{1,2,3,4,5,6}` 합집합, `a - b` = `{1, 2}` 차집합.</details>
3. `lst = [3,1,4]`에서 `lst.sort()`와 `sorted(lst)`의 차이는?
   <details><summary>정답</summary>`lst.sort()`는 원본을 직접 정렬하며 반환값은 None이다. `sorted(lst)`는 원본을 그대로 두고 **정렬된 새 리스트**를 반환한다. 원본 보존 여부가 핵심 차이.</details>

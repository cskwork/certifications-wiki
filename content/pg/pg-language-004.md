# Python 핵심 문법

> 🔥 **매회 출제** (priority 3)

![[pg-language-004.svg]]

## 🌱 왜 배우나

리스트(여러 값을 순서대로 모아둔 것)에서 "3번째부터 7번째까지만 꺼내고 싶다"거나 "짝수 항목만 골라 새 리스트를 만들고 싶다"는 일은 프로그래밍에서 매우 흔하다. 이런 작업을 매번 반복문으로 쓰면 코드가 길어지고 실수하기 쉽다.

마치 긴 두루마리에서 원하는 구간만 가위로 오려 내거나, 체로 원하는 알갱이만 걸러내는 것처럼 — Python은 이런 일을 한 줄로 표현하는 문법을 제공한다. 슬라이싱(원하는 구간만 잘라내기)과 컴프리헨션(조건에 맞는 것만 골라 새로 만들기)이 그것이다.

## 📖 핵심 개념

슬라이싱은 `[start:end:step]` 형식으로 리스트나 문자열의 일부를 잘라내는 문법이다. 원본을 변경하지 않고 새로운 결과를 돌려준다. 딕셔너리(Dictionary)는 이름표(키, key)와 값(value)을 쌍으로 저장하는 자료형이다. 예를 들어 `{'이름': '철수', '나이': 15}`처럼 쓴다. 컴프리헨션(Comprehension)은 반복문과 조건을 한 줄로 압축해서 새 리스트나 딕셔너리를 만드는 문법이다. 집합(Set)은 중복 없이 값을 모아둔 자료형으로, 수학의 집합 연산(교집합, 합집합, 차집합)을 바로 쓸 수 있다.

## 🔍 시각화

```
슬라이싱 인덱스 이해:

문자열: a  b  c  d  e  f  g
인덱스: 0  1  2  3  4  5  6
       -7 -6 -5 -4 -3 -2 -1

s[2:5]  → c d e  (2번부터 4번까지, 5번 미포함)
s[::-1] → g f e d c b a  (역순)

딕셔너리 컴프리헨션 흐름:

{k: v for k, v in data.items() if v % 2 == 0}
  │         │                    │
  │         │                    └─ 조건: 짝수만
  │         └─ 반복: 모든 (키, 값) 쌍
  └─ 결과: 조건 통과한 것으로 새 딕셔너리 생성
```

## ↔️ 이웃 개념 구분

- **리스트(list) vs 딕셔너리(dict)**: 리스트는 순서대로 번호(인덱스)로 접근, 딕셔너리는 이름표(키)로 접근.
- **sort() vs sorted()**: `sort()`는 원본 리스트 자체를 바꿈, `sorted()`는 원본은 그대로 두고 새 리스트를 돌려줌.

**핵심 용어**

- **슬라이싱 `[start:end:step]`**: 리스트나 문자열의 일부를 잘라내는 문법. end 인덱스는 포함하지 않는다. `[::-1]`은 역순
- **dict.keys()**: 딕셔너리의 키(이름표) 목록을 반환
- **dict.values()**: 딕셔너리의 값 목록을 반환
- **dict.items()**: 딕셔너리의 (키, 값) 쌍을 튜플(tuple, 변경 불가능한 묶음) 형태로 반환
- **리스트 컴프리헨션(List Comprehension)**: `[표현식 for 변수 in 반복가능 if 조건]` — 조건에 맞는 값만 골라 새 리스트를 한 줄로 만드는 문법
- **딕셔너리 컴프리헨션(Dict Comprehension)**: `{k: v for k, v in ...}` — 조건에 맞는 키-값 쌍으로 새 딕셔너리를 만드는 문법
- **집합 연산**: `&` 교집합(둘 다 가진 것), `|` 합집합(하나라도 가진 것), `-` 차집합(나만 가진 것)

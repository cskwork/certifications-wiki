# C언어 포인터 기초

> 🔥 **매회 출제** (priority 3)

![[pg-language-001.svg]]

## 🌱 왜 배우나

친구에게 "우리 집"이라고 말하는 것과 "서울시 강남구 ○○로 12"라고 주소를 말해주는 것은 다르다. 전자는 내가 친구를 데려가야 하지만, 후자는 주소만 알려주면 친구가 알아서 찾아가고 심지어 내 집 물건도 바꿔놓을 수 있다. C의 포인터는 바로 이 "주소지"다. 값을 통째로 복사해서 넘기는 대신 변수의 주소만 넘겨서 원본을 직접 고치거나, 크기가 큰 데이터를 저렴하게 전달할 수 있게 하려고 이 개념이 등장했다.

## 📖 핵심 개념

포인터(Pointer)는 **메모리 주소를 저장하는 변수**이다. 선언 시 `*` 기호를 사용하며, 변수의 주소를 얻을 때는 주소 연산자 `&`를, 포인터가 가리키는 값에 접근할 때는 역참조 연산자 `*`를 사용한다. 포인터를 통해 변수의 값을 간접적으로 읽거나 수정할 수 있다.

**핵심 용어**

- **포인터 선언**: `int *p;` (정수형 포인터 변수 p 선언, 아직 어떤 주소도 가리키지 않음)
- **주소 연산자(&)**: `p = &a;` (변수 a의 메모리 주소를 포인터 p에 저장)
- **역참조 연산자(*)**: `*p` (포인터 p가 가리키는 주소에 저장된 값에 접근)
- **포인터와 배열**: 배열명은 첫 번째 원소의 주소를 나타내는 포인터 상수. `arr[i]`는 `*(arr+i)`와 동일
- **NULL 포인터**: 아무것도 가리키지 않는 포인터. 초기화되지 않은 포인터 사용 시 오류 발생 가능

## ✅ 이해 확인

1. `&` 연산자와 `*` 연산자의 역할은 각각 무엇인가?
   <details><summary>정답</summary>`&`는 변수의 주소를 얻는 **주소 연산자**, `*`는 포인터가 가리키는 주소의 값에 접근하는 **역참조 연산자**다.</details>
2. 다음 코드에서 `*p`와 `p`는 각각 무엇을 출력하는가?
   ```c
   int a = 10; int *p = &a;
   ```
   <details><summary>정답</summary>`*p`는 10(a의 값), `p`는 a의 메모리 주소(예: 0x7ffeefbff4ac 같은 16진수 주소)를 출력한다.</details>
3. 배열 `int arr[] = {10, 20, 30};`일 때 `*(arr + 1)`과 `arr[1]`은 같은가?
   <details><summary>정답</summary>같다. 배열명 arr은 첫 원소의 주소이므로 `arr+1`은 두 번째 원소의 주소이고, 이를 역참조한 `*(arr+1)`은 20이다. C에서 `arr[i]`는 `*(arr+i)`로 정의되어 있다.</details>

## 🎯 시험 응용

> C언어 포인터 문제는 실기 단골 출제 유형이다. `&`(주소 연산자)와 `*`(역참조 연산자)의 역할을 반드시 구분할 것. 포인터를 이용한 **값 교환(swap)** 문제, 포인터와 배열의 관계(`*(arr+i)` == `arr[i]`), 이중 포인터(`**pp`)를 활용한 출력 결과 추적 문제가 빈출된다. 코드 트레이싱 시 변수의 주소와 값을 표로 정리하면 실수를 줄일 수 있다.

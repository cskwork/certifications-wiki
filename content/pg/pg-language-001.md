# C언어 포인터 기초

> 🔥 **매회 출제** (priority 3)

![[pg-language-001.svg]]

## 🌱 왜 배우나

친구에게 "우리 집에 올래?"라고 하면 내가 직접 데려가야 한다. 하지만 "서울시 강남구 ○○로 12번지"라고 주소를 알려주면, 친구가 혼자서 찾아가고 심지어 내 집에 있는 물건을 바꿔놓을 수도 있다.

C언어의 포인터는 바로 이 "주소"에 해당한다. 값을 통째로 복사해서 넘기는 대신, 변수(값을 담아두는 이름표 붙은 공간)가 저장된 위치(주소)만 알려주면 원본을 직접 읽거나 고칠 수 있다. 크기가 큰 데이터도 주소 하나만 전달하면 되니 효율적이다. 이런 이유로 포인터가 등장했다.

## 📖 핵심 개념

포인터(Pointer)는 메모리 주소(컴퓨터가 값을 저장해둔 위치 번호)를 저장하는 변수다. 쉽게 말해 "어디에 있는지"를 기억해 두는 변수다. 선언할 때 `*` 기호를 사용한다. 변수의 주소를 얻으려면 주소 연산자 `&`를 쓰고, 포인터가 가리키는 주소에 저장된 값을 꺼내 보려면 역참조 연산자 `*`를 쓴다. 포인터를 통해 다른 변수의 값을 간접적으로 읽거나 수정할 수 있다. 이것이 포인터의 핵심 기능이다.

## 🔍 시각화

```
변수 a와 포인터 p의 관계:

        메모리
주소     ┌─────────┐
0x100   │  a = 10  │ ◀─── 변수 a가 여기 저장됨
        ├─────────┤
0x200   │ p = 0x100│ ◀─── 포인터 p는 a의 주소를 저장
        └─────────┘

  &a  → 0x100  (a의 주소를 알려줘)
  *p  → 10     (p가 가리키는 곳의 값을 꺼내)
  *p = 20      (p가 가리키는 곳의 값을 20으로 바꿔)
  → a도 20이 됨
```

## ↔️ 이웃 개념 구분

- **주소 연산자(&) vs 역참조 연산자(*)**: `&`는 "이 변수의 주소를 알려줘", `*`는 "이 주소에 가서 값을 꺼내/바꿔"
- **포인터 vs 일반 변수**: 일반 변수는 값 자체를 저장, 포인터는 다른 변수의 위치(주소)를 저장

**핵심 용어**

- **포인터 선언**: `int *p;` — 정수형 값이 저장된 주소를 담을 변수 p를 만든다. 아직 어떤 주소도 가리키지 않는 상태
- **주소 연산자(&, ampersand)**: `p = &a;` — 변수 a가 저장된 메모리 위치(주소)를 포인터 p에 저장
- **역참조 연산자(*, dereference)**: `*p` — 포인터 p가 가리키는 주소에 저장된 값에 접근
- **포인터와 배열의 관계**: 배열 이름은 첫 번째 원소의 주소를 나타낸다. `arr[i]`는 `*(arr+i)`와 같은 뜻
- **NULL 포인터**: 아무것도 가리키지 않는 포인터. 초기화하지 않고 사용하면 프로그램 오류가 발생할 수 있다

## ✅ 스스로 가르쳐보기

이 내용을 처음 듣는 친구에게 설명한다고 생각하고, 본인만의 비유로 **포인터**를 한 문장으로 정의해보세요.

**체크포인트** — 아래 항목을 스스로 설명할 수 있는지 확인하세요:
- `&`와 `*`가 각각 하는 일이 무엇인지
- `*p = 20;`을 실행하면 왜 변수 a의 값도 바뀌는지
- 배열 이름이 포인터처럼 동작하는 이유
- NULL 포인터를 사용하면 왜 문제가 생기는지

## 🎯 시험 응용

> C언어 포인터 문제는 실기 단골 출제 유형이다. `&`(주소 연산자)와 `*`(역참조 연산자)의 역할을 반드시 구분할 것. 포인터를 이용한 **값 교환(swap)** 문제, 포인터와 배열의 관계(`*(arr+i)` == `arr[i]`), 이중 포인터(`**pp`)를 활용한 출력 결과 추적 문제가 빈출된다. 코드 트레이싱 시 변수의 주소와 값을 표로 정리하면 실수를 줄일 수 있다.

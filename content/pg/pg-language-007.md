# C언어 배열과 반복문

> 🔥 **매회 출제** (priority 3)

![[pg-language-007.svg]]

## 핵심 개념

배열(Array)은 **같은 타입의 데이터를 연속된 메모리**에 저장하는 자료구조이다. 인덱스는 0부터 시작하며, 반복문(for, while)과 결합하여 정렬, 탐색, 집계 등의 코드 추적 문제가 매회 출제된다.

## 키워드

- **배열 선언**: `int a[5]` 또는 `int a[] = {1,2,3}` (크기 자동 결정)
- **인덱스**: `a[0]`부터 `a[n-1]`까지. 범위 초과 시 정의되지 않은 동작
- **버블 정렬**: 인접 원소를 비교·교환하여 정렬. 이중 for문 패턴
- **선택 정렬**: 최솟값(최댓값)을 찾아 맨 앞(뒤)과 교환
- **교환(swap)**: `tmp = a[i]; a[i] = a[j]; a[j] = tmp;`

## 🎯 기출 포인트

> - **2025-1회**: 배열 정렬(삽입 정렬 변형) 후 출력 결과 추적. 답: 4 BACDE > - **매회 출제**: 이중 for문 + 배열 교환 패턴은 정보처리기사 실기의 핵심 단골 유형 > - **트레이싱 팁**: 배열 상태를 반복마다 표로 기록하면 실수를 줄일 수 있다 > - **주의**: `a[j]`와 `a[j+1]` 비교 시 j의 범위를 벗어나지 않는지 확인

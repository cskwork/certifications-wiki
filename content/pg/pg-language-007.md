# C언어 배열과 반복문

> 🔥 **매회 출제** (priority 3)

![[pg-language-007.svg]]

## 🌱 왜 배우나

학생 30명의 점수를 저장하려고 `score1, score2, ..., score30` 변수를 30개 만들면, 평균을 구하는 코드도 30줄이 된다. 배열(Array)은 "이름 하나에 여러 칸을 묶어 두자"는 아이디어다.

우편함이 101호부터 130호까지 한 건물 안에 번호가 붙어 있는 것과 같다. 반복문(같은 코드를 정해진 횟수만큼 되풀이하는 구문)과 결합하면 `score[i]`의 i만 바꿔가며 한 줄짜리 코드로 30명을 한 번에 처리할 수 있다. 대량의 비슷한 데이터를 효율적으로 다루기 위해 배열과 반복문이 짝을 이뤄 등장했다.

## 📖 핵심 개념

배열(Array)은 같은 타입(종류)의 데이터를 연속된 메모리(저장 공간)에 나란히 저장하는 자료구조다. 각 칸에는 0부터 시작하는 번호(인덱스, index)가 붙어 있어서, 번호만 알면 바로 접근할 수 있다. 반복문(for, while)은 같은 동작을 여러 번 되풀이하는 구문이다. 배열과 결합하면 정렬(데이터를 크기 순서로 나열하기), 탐색(원하는 값 찾기), 집계(합계·평균 구하기) 등을 간결하게 작성할 수 있다. 시험에서는 이중 for문(반복문 안에 반복문)과 배열 값 교환 패턴이 매회 출제된다.

## 🔍 시각화

```
배열 구조:

인덱스:  [0]  [1]  [2]  [3]  [4]
         ┌────┬────┬────┬────┬────┐
  a[] =  │  3 │  1 │  4 │  1 │  5 │
         └────┴────┴────┴────┴────┘

버블 정렬 과정 (인접한 둘을 비교해서 큰 걸 뒤로 보내기):

i=0: [1, 1, 3, 4, 5]  ← 가장 큰 5가 맨 뒤로 확정
i=1: [1, 1, 3, 4, 5]  ← 4가 뒤에서 두 번째 확정
i=2: [1, 1, 3, 4, 5]  ← 3 확정
i=3: [1, 1, 3, 4, 5]  ← 전부 확정

값 교환(swap) 3단계:

  tmp = a[j]      a[j]의 값을 임시 보관
  a[j] = a[j+1]   a[j]에 a[j+1]의 값을 넣음
  a[j+1] = tmp    a[j+1]에 임시 보관한 값을 넣음
```

## ↔️ 이웃 개념 구분

- **배열 vs 연결 리스트**: 배열은 번호(인덱스)로 바로 접근 가능하지만 크기가 고정, 연결 리스트는 크기 변경이 자유롭지만 번호로 바로 접근 불가.
- **버블 정렬 vs 선택 정렬**: 버블 정렬은 인접한 둘을 비교·교환, 선택 정렬은 전체에서 최솟값을 찾아 맨 앞과 교환.

**핵심 용어**

- **배열 선언**: `int a[5]` 또는 `int a[] = {1,2,3}` — 같은 타입의 값을 연속으로 저장하는 공간. 뒤의 형태는 초기값에서 크기를 자동으로 결정
- **인덱스(index)**: 배열의 각 칸에 붙는 번호. `a[0]`부터 `a[n-1]`까지. 범위를 벗어나면 예측 불가능한 오류 발생
- **버블 정렬(Bubble Sort)**: 인접한 두 원소를 비교하여 순서가 잘못되면 교환하는 정렬 방법. 이중 for문 패턴
- **선택 정렬(Selection Sort)**: 전체에서 가장 작은(또는 큰) 값을 찾아 맨 앞(또는 뒤)과 교환하는 정렬 방법
- **교환(swap)**: 두 변수의 값을 맞바꾸는 방법. `tmp = a[i]; a[i] = a[j]; a[j] = tmp;` — 임시 변수 tmp가 반드시 필요

## ✅ 스스로 가르쳐보기

이 내용을 처음 듣는 친구에게 설명한다고 생각하고, 본인만의 비유로 **배열과 반복문의 관계**를 한 문장으로 정의해보세요.

**체크포인트** — 아래 항목을 스스로 설명할 수 있는지 확인하세요:
- 배열의 인덱스가 0부터 시작하는 이유와 마지막 유효 인덱스가 `n-1`인 이유
- 값 교환 시 임시 변수(tmp)가 없으면 왜 실패하는지
- 버블 정렬에서 바깥 루프가 진행될수록 안쪽 범위가 줄어드는 이유
- 배열 이름이 포인터처럼 동작한다는 것이 무슨 뜻인지

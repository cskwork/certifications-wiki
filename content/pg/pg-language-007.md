# C언어 배열과 반복문

> 🔥 **매회 출제** (priority 3)

![[pg-language-007.svg]]

## 🌱 왜 배우나

학생 30명 점수를 저장하려고 `score1, score2, ..., score30` 변수를 30개 만들면, 평균을 구하는 코드도 30줄이 된다. 너무 비효율적이다. 배열은 "이름 하나에 여러 칸을 묶어 두자"는 아이디어로, 우편함이 101호부터 130호까지 한 건물 안에 번호 붙어 있는 것과 같다. 반복문과 결합하면 `score[i]`의 i만 바꿔가며 한 줄짜리 코드로 30명을 처리할 수 있다. 대량의 비슷한 데이터를 통째로 다루기 위해 배열과 반복문이 짝을 이뤄 등장했다.

## 📖 핵심 개념

배열(Array)은 **같은 타입의 데이터를 연속된 메모리**에 저장하는 자료구조이다. 인덱스는 0부터 시작하며, 반복문(for, while)과 결합하여 정렬, 탐색, 집계 등의 코드 추적 문제가 매회 출제된다.

**핵심 용어**

- **배열 선언**: `int a[5]` 또는 `int a[] = {1,2,3}` (크기 자동 결정)
- **인덱스**: `a[0]`부터 `a[n-1]`까지. 범위 초과 시 정의되지 않은 동작
- **버블 정렬**: 인접 원소를 비교·교환하여 정렬. 이중 for문 패턴
- **선택 정렬**: 최솟값(최댓값)을 찾아 맨 앞(뒤)과 교환
- **교환(swap)**: `tmp = a[i]; a[i] = a[j]; a[j] = tmp;`

## ✅ 이해 확인

1. C에서 `int a[5]` 배열의 유효한 인덱스 범위는?
   <details><summary>정답</summary>`a[0]`부터 `a[4]`까지. 크기 5이지만 인덱스는 0부터 시작하므로 `a[5]`는 범위 초과(정의되지 않은 동작)다.</details>
2. 두 변수 값을 교환하는 `tmp = a[i]; a[i] = a[j]; a[j] = tmp;` 코드에서 `tmp`를 생략하면 어떻게 되는가?
   <details><summary>정답</summary>`a[i] = a[j];`를 먼저 실행하면 `a[i]`의 원래 값이 사라진다. 이후 `a[j] = a[i];`를 해도 두 변수가 같은 값(원래 a[j])이 되어 교환이 실패한다. 임시 변수 tmp는 값을 "잠깐 보관"하는 역할.</details>
3. 버블 정렬 이중 for문에서 `j < 4 - i`처럼 바깥 루프가 진행될수록 안쪽 범위가 줄어드는 이유는?
   <details><summary>정답</summary>한 바퀴를 돌 때마다 가장 큰 값이 맨 뒤로 확정되므로, 다음 바퀴는 이미 정렬된 뒷부분을 다시 비교할 필요가 없다. 불필요한 비교를 줄여 효율을 높이기 위함.</details>

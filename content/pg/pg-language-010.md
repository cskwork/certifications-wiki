# C언어 진수 변환과 비트 연산

> 🔥 **매회 출제** (priority 3)

![[pg-language-010.svg]]

## 🌱 왜 배우나

우리는 손가락이 10개라 숫자를 10개 단위(0~9)로 세는 게 자연스럽다. 이걸 10진수(decimal)라고 부른다. 컴퓨터는 전기 스위치가 켜짐(1)과 꺼짐(0) 두 상태만 구분할 수 있어서, 숫자를 0과 1 두 개로 표현하는 2진수(binary)가 모국어다. 2진수는 숫자가 너무 길어지니까, 2진수 네 자리를 한 글자로 줄여 쓰는 방법이 16진수(hexadecimal)다. 메모리 주소나 웹 컬러 코드(#FF5733)가 16진수를 쓰는 이유다. 서로 다른 진법(숫자 세는 방식)끼리 변환하는 것은, 한국어와 영어를 통역하는 것과 같다. 또 특정 비트(2진수의 한 자릿수)만 켜거나 끄는 조작이 필요할 때 비트 연산자(`& | ^ ~ << >>`)를 사용한다.

## 📖 핵심 개념

진수란 숫자를 몇 개의 기호로 세느냐를 뜻한다. 10진수는 0~9 열 개, 2진수는 0~1 두 개, 8진수(octal)는 0~7 여덟 개, 16진수는 0~9와 A~F 열여섯 개를 쓴다. C언어에서 10진수를 다른 진수로 바꾸려면 "그 진수의 밑(base)으로 나누고, 나머지를 역순으로 읽는다"라는 원리를 반복한다. 예를 들어 87을 16진수로 바꾸려면 87÷16=5 나머지 7, 5÷16=0 나머지 5, 역순으로 읽으면 57이다. printf 함수의 서식 문자(format specifier)로 `%d`(10진수), `%o`(8진수), `%x`(소문자 16진수), `%X`(대문자 16진수)를 쓰면 자동 변환 출력도 가능하다. 비트 연산자는 정수를 2진수로 놓고 각 자릿수(비트)끼리 논리 계산하는 도구다. AND(`&`)는 둘 다 1일 때만 1, OR(`|`)는 하나라도 1이면 1, XOR(`^`)는 서로 다르면 1, NOT(`~`)은 반전, 시프트(`<< >>`)는 비트를 좌우로 밀어서 곱셈·나눗셈 효과를 낸다.

## 🔍 시각화

```
┌─────────── 10진수 87 → 16진수 변환 ───────────┐
│                                                │
│  87 ÷ 16 = 5  나머지 7  → hex[0] = '7'        │
│   5 ÷ 16 = 0  나머지 5  → hex[1] = '5'        │
│                                                │
│  역순 출력: 5  7  →  "57"                      │
└────────────────────────────────────────────────┘

┌─────────── 비트 AND 연산 ─────────────────────┐
│  a = 0x1A  →  0 0 0 1  1 0 1 0  (26)         │
│  b = 0x0F  →  0 0 0 0  1 1 1 1  (15)         │
│  ──────────────────────────────               │
│  a & b     →  0 0 0 0  1 0 1 0  (0A = 10)    │
│  (둘 다 1인 자리만 1)                          │
└───────────────────────────────────────────────┘

┌─────────── 왼쪽 시프트 ───────────────────────┐
│  c = 3     →  0 0 0 0  0 0 1 1               │
│  c << 2    →  0 0 0 0  1 1 0 0  (12 = 3×4)   │
│  (비트가 왼쪽으로 2칸 이동, 빈자리는 0)        │
└───────────────────────────────────────────────┘
```

## ↔️ 이웃 개념 구분

- **진수 변환 vs 비트 연산**: 진수 변환은 같은 숫자를 다른 표기법으로 바꾸는 것이고, 비트 연산은 2진수 상태에서 각 자릿수를 논리적으로 조작하는 것이다.
- **`<<` 시프트 vs `*` 곱셈**: `n << k`는 n × 2^k와 결과가 같지만, 비트 단위로 밀어내는 연산이라 곱셈보다 빠르다.

**핵심 용어**

- **진수(numeral system)**: 숫자를 몇 개의 기호로 세느냐를 정하는 방식
- **printf 서식**: `%d`(decimal, 10진수), `%o`(octal, 8진수), `%x`/`%X`(hexadecimal, 16진수)
- **0x 접두어**: 16진수 리터럴(코드에 직접 쓴 값)을 나타냄. `0x1A` = 26
- **0 접두어**: 8진수 리터럴을 나타냄. `010` = 8
- **비트 AND(`&`)**: 두 비트 모두 1이면 1, 그 외 0
- **비트 OR(`|`)**: 하나라도 1이면 1
- **비트 XOR(`^`, exclusive or)**: 서로 다르면 1, 같으면 0
- **비트 NOT(`~`)**: 모든 비트를 반전(0→1, 1→0)
- **왼쪽 시프트(`<<`)**: 비트를 왼쪽으로 이동. `n << 1`은 n × 2
- **오른쪽 시프트(`>>`)**: 비트를 오른쪽으로 이동. `n >> 1`은 n ÷ 2(몫)

# C언어 진수 변환과 비트 연산

> 🔥 **매회 출제** (priority 3)

![[pg-language-010.svg]]

## 🌱 왜 배우나

사람은 손가락이 10개라 10진수가 익숙하지만, 컴퓨터는 전기 스위치 on/off로 동작해서 2진수가 모국어다. 메모리 주소나 컬러 코드(#FF5733)는 2진수를 짧게 표기하려고 16진수를 쓴다. 이는 사람마다 모국어가 다른 것과 같다. 서로 다른 진법을 주고받으려면 "한국어 ↔ 영어" 통역처럼 변환이 필요하다. 또 특정 비트만 켜거나 끄는 조작(권한 플래그, 마스킹 등)을 위해 비트 연산자 `& | ^ ~ << >>`가 언어 차원에서 제공된다.

## 📖 핵심 개념

컴퓨터는 2진수로 데이터를 처리하며, 프로그래밍에서는 10진수, 2진수, 8진수, 16진수 간 변환이 빈번하다. C언어의 비트 연산자는 비트 단위로 데이터를 조작하며, 진수 변환 코드와 비트 연산 결과 추적이 기출파괴 포인트로 등장했다.

**핵심 용어**

- **printf 서식**: `%d`(10진수), `%o`(8진수), `%x/%X`(16진수)
- **0x 접두어**: 16진수 리터럴. `0x1A` = 26
- **0 접두어**: 8진수 리터럴. `010` = 8
- **비트 AND(&)**: 두 비트 모두 1이면 1
- **비트 OR(|)**: 하나라도 1이면 1
- **비트 XOR(^)**: 서로 다르면 1
- **비트 NOT(~)**: 비트 반전
- **왼쪽 시프트(<<)**: 비트를 왼쪽으로 이동. `n << 1` = n × 2
- **오른쪽 시프트(>>)**: 비트를 오른쪽으로 이동. `n >> 1` = n / 2

## ✅ 이해 확인

1. printf 서식에서 `%d`, `%o`, `%x`는 각각 어떤 진수로 출력하는가?
   <details><summary>정답</summary>`%d`는 10진수, `%o`는 8진수, `%x`는 소문자 16진수(`%X`는 대문자 16진수)로 정수를 출력한다.</details>
2. 10진수 26을 16진수로 변환하면? 변환 절차는?
   <details><summary>정답</summary>`1A`. 26 ÷ 16 = 1 나머지 10(=A), 1 ÷ 16 = 0 나머지 1. 나머지를 역순으로 읽어 `1A`. 나머지가 10 이상이면 A~F로 표기한다.</details>
3. `int c = 3;`일 때 `c << 2`와 `c >> 1`의 결과와 의미는?
   <details><summary>정답</summary>`c << 2` = 12 (3 × 2² = 12, 왼쪽 시프트는 2배씩 곱하는 효과). `c >> 1` = 1 (3 ÷ 2 = 1, 오른쪽 시프트는 2로 나눈 몫). 비트 이동은 곱셈/나눗셈보다 빠르다.</details>

## 🎯 시험 응용

> - **2025-1회**: 10진수 → 16진수 변환 코드 출력 추적 (답: 908). **기출파괴 포인트**로 수험생 다수 오답 > - **출제 패턴**: while문으로 나머지 연산 반복 → 역순 출력. 진수 변환 원리를 코드로 구현 > - **비트 연산**: AND/OR/XOR/시프트 연산 결과 추적. 2진수로 변환 후 비트별 계산 > - **주의**: `%X`는 대문자, `%x`는 소문자 16진수 출력

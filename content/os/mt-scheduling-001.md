# CPU 스케줄링 알고리즘 (FCFS, SJF, SRT, RR, 우선순위)

> 🔥 **매회 출제** (priority 3)

![[mt-scheduling-001.svg]]

## 🌱 왜 배우나

CPU(Central Processing Unit, 중앙처리장치)는 한 번에 하나의 프로세스(실행 중인 프로그램)만 처리할 수 있는데, 수십~수백 개의 프로세스가 동시에 CPU를 요구한다. 아무 규칙 없이 순서를 정하면, 오래 걸리는 작업 뒤에 선 짧은 작업이 한참을 기다려야 한다. 은행 창구에 비유하면, "먼저 온 사람 순서대로 처리할 것인가?", "간단한 업무를 먼저 해 줄 것인가?", "번호표를 일정 시간 단위로 돌려가며 처리할 것인가?"에 따라 평균 대기시간이 완전히 달라진다. 이 "순서 정하기 규칙"이 CPU 스케줄링 알고리즘이다.

## 📖 핵심 개념

CPU 스케줄링은 "준비 큐(CPU를 기다리는 프로세스 대기열)에서 누구에게 먼저 CPU를 줄 것인가"를 결정하는 규칙이다. 크게 두 가지 방식이 있다. 비선점(Non-preemptive) 방식은 한 프로세스가 CPU를 잡으면 스스로 끝낼 때까지 뺏지 않는다. 선점(Preemptive) 방식은 더 급한 프로세스가 오면 실행 중인 프로세스를 중단시키고 CPU를 넘긴다. 각 알고리즘은 "어떤 기준으로 순서를 정하느냐"가 다르다. 시험에서는 프로세스별 도착시간과 실행시간(버스트 시간)이 주어지고, 평균 대기시간이나 평균 반환시간을 계산하는 문제가 나온다.

## 🔍 시각화

```
 준비 큐 (CPU를 기다리는 줄)
 ┌────┬────┬────┐
 │ P3 │ P2 │ P1 │ ──→ CPU ──→ 완료
 └────┴────┴────┘

 [FCFS] 먼저 온 순서대로:  P1 → P2 → P3
 [SJF]  짧은 작업 먼저:    P3 → P2 → P1
 [RR]   돌아가며 조금씩:   P1(2) → P2(2) → P3(2) → P1(2) → P2(2) → P1(2)

 ※ 괄호 안 숫자 = 타임퀀텀(한 번에 실행하는 시간 단위)
```

## ↔️ 이웃 개념 구분

- **SJF vs SRT**: SJF(Shortest Job First)는 비선점 — 일단 시작하면 끝까지 실행. SRT(Shortest Remaining Time)는 SJF의 선점 버전 — 실행 도중에 "남은 시간이 더 짧은" 프로세스가 도착하면 즉시 교체.
- **FCFS vs RR**: FCFS(First Come First Served)는 먼저 온 순서대로 끝까지 처리(비선점). RR(Round Robin)은 정해진 시간(타임퀀텀)만큼만 실행하고 다음 프로세스에게 넘김(선점). 타임퀀텀이 무한히 크면 FCFS와 같아진다.

**핵심 용어**

- **도착시간(Arrival Time)**: 프로세스가 준비 큐에 도착한 시각
- **버스트 시간(Burst Time, 실행시간)**: CPU를 사용하는 데 필요한 시간
- **완료시간(Completion Time)**: 프로세스가 실행을 끝낸 시각
- **반환시간(Turnaround Time)**: 도착부터 완료까지 걸린 전체 시간 = 완료시간 - 도착시간
- **대기시간(Waiting Time)**: 준비 큐에서 기다린 시간 = 반환시간 - 버스트시간
- **선점(Preemptive)**: 실행 중인 프로세스를 강제로 중단시킬 수 있는 방식
- **비선점(Non-preemptive)**: 프로세스가 스스로 CPU를 반납할 때까지 기다리는 방식
- **타임퀀텀(Time Quantum)**: RR(Round Robin, 라운드 로빈)에서 한 프로세스가 한 번에 CPU를 쓰는 시간 단위
- **에이징(Aging)**: 오래 기다린 프로세스의 우선순위를 점차 올려 기아(Starvation, 영원히 실행되지 못하는 상태)를 방지하는 기법
- **콘보이 효과(Convoy Effect)**: FCFS에서 긴 작업 뒤에 짧은 작업들이 오래 기다리는 현상

## ✅ 스스로 가르쳐보기

"FCFS, SJF, RR 세 가지 알고리즘이 각각 어떤 기준으로 순서를 정하는지 설명하고, 같은 프로세스 집합에서 어떤 알고리즘이 평균 대기시간이 가장 짧은지 친구에게 말해 보세요."

체크포인트:
- 선점과 비선점의 차이를 한 줄로 말할 수 있는가?
- SJF가 평균 대기시간이 최적인 이유를 설명할 수 있는가?
- RR에서 타임퀀텀이 너무 작으면 무슨 문제가 생기는지 말할 수 있는가?
- 기아(Starvation)와 에이징(Aging)의 관계를 설명할 수 있는가?

## 🎯 시험 응용

> **2025-2회**: SJF/SRT 비교 + 라운드 로빈 타임퀀텀=3일 때 평균 반환시간 11.75ms 계산 문제 출제. > **2025-2회**: 라운드 로빈에서 타임퀀텀이 클수록 FCFS에 가까워지고, 작을수록 문맥교환 오버헤드 증가. > **2024-2회**: SRT 평균 대기시간 6.5ms 계산 문제 — 각 타임슬롯마다 남은 버스트시간 재계산 필수. > 계산 문제는 **간트 차트(Gantt Chart)**를 직접 그리며 타임라인을 시각화하면 오류 방지.

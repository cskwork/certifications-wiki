# 응용 계층 프로토콜 (HTTP, HTTPS, FTP, SMTP, DNS, SNMP, SSH)

> 🔥 **매회 출제** (priority 3)

![[nw-protocol-003.svg]]

## 🌱 왜 배우나

한 컴퓨터에서 웹 브라우저, 메일 클라이언트, 원격 접속 프로그램이 동시에 돌아간다고 상상해 보자. 네트워크 카드로 들어온 데이터를 어느 프로그램에 전달할지 구분할 방법이 없으면 모든 통신이 뒤섞인다. 마치 큰 아파트 단지에 동·호수(포트 번호)가 없으면 택배 기사가 어느 집에 물건을 줄지 알 수 없는 것과 같다. 그래서 각 서비스마다 고정된 포트 번호(HTTP 80, SSH 22, DNS 53 등)를 약속으로 정해, 같은 IP 아래에서도 수많은 응용 프로토콜이 충돌 없이 공존할 수 있게 되었다.

## 📖 핵심 개념

OSI 7계층 중 응용 계층(Layer 7)에 위치한 프로토콜들은 각각 고유한 포트 번호와 기능을 가진다. 정보처리기사 시험에서는 프로토콜 약어, 포트 번호, 역할의 매핑이 반드시 출제된다. 특히 SSH(22), HTTP(80), HTTPS(443), FTP(20/21), SMTP(25), DNS(53), SNMP(161) 조합은 핵심 암기 대상이다.

## ✅ 이해 확인

1. **SSH**와 **Telnet**의 포트 번호와 보안상 차이점은?
   <details><summary>정답</summary>SSH는 22번(암호화), Telnet은 23번(평문). 스니핑에 취약한 Telnet은 현재 SSH로 대체되었다.</details>
2. **FTP**가 두 개의 포트(20, 21)를 사용하는 이유는 무엇인가?
   <details><summary>정답</summary>21번은 제어(명령), 20번은 실제 데이터 전송. 명령과 데이터 채널을 분리해 대용량 전송 중에도 추가 명령을 보낼 수 있다.</details>
3. **SMTP**, **POP3**, **IMAP**의 역할과 포트를 구분하면?
   <details><summary>정답</summary>SMTP(25)는 송신, POP3(110)는 수신 후 서버에서 삭제, IMAP(143)은 수신 후 서버에 유지. "보내는 건 SMTP 하나, 받는 건 두 개"로 기억.</details>

## 🎯 시험 응용

> **2025-2회**: SSH 포트 번호 22 직접 출제 — "SSH가 사용하는 포트 번호는?" > **매회 반복**: 프로토콜 약어와 포트 번호 매핑 (특히 FTP 20/21 이중 포트 주의) > **혼동 주의**: FTP는 20(데이터 전송)과 21(제어 명령) 두 포트를 사용함 > **SMTP vs POP3**: SMTP는 **송신(25)**, POP3는 **수신(110)** — 방향으로 구분

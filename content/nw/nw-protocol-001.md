# OSI 7계층 모델

> 🔥 **매회 출제** (priority 3)

![[nw-protocol-001.svg]]

## 🌱 왜 배우나

국제 우편을 보낸다고 생각해 보자. 편지를 쓰는 사람, 봉투에 넣는 사람, 우체국에서 분류하는 사람, 비행기에 싣는 사람, 배달하는 사람이 각각 자기 역할만 맡는다. 한 단계의 방식이 바뀌어도 다른 단계에는 영향이 없다. 컴퓨터 통신도 마찬가지다. 서로 다른 회사가 만든 장비끼리 대화하려면 "누가 전기 신호를 보내고, 누가 주소를 붙이고, 누가 오류를 확인하는지" 역할을 나눠야 한다. 이 역할 분담을 7단계로 정리한 것이 OSI(Open Systems Interconnection, 개방형 시스템 간 상호 연결) 7계층 모델이다.

## 📖 핵심 개념

OSI 7계층 모델은 ISO(International Organization for Standardization, 국제표준화기구)가 만든 네트워크 통신의 표준 설계도다. "컴퓨터가 데이터를 주고받는 전체 과정"을 7개 층으로 나눠, 각 층이 딱 하나의 역할만 맡는다. 아래층은 전기 신호 같은 물리적 작업을, 위층으로 갈수록 사람이 직접 쓰는 프로그램(웹 브라우저, 이메일 등)에 가까운 작업을 담당한다. 각 층은 데이터를 주고받을 때 고유한 이름(PDU, Protocol Data Unit — 프로토콜 데이터 단위)을 붙여서 구분한다. 데이터를 보낼 때는 위층에서 아래층으로 내려가며 각 층이 헤더(머리말 정보)를 하나씩 추가하는데, 이 과정을 캡슐화(Encapsulation)라 한다. 받을 때는 반대로 아래층부터 헤더를 하나씩 벗겨낸다.

## ↔️ 이웃 개념 구분

- **OSI 7계층 vs TCP/IP 4계층**: OSI는 이론적 참조 모델(7층)이고, TCP/IP는 실제 인터넷에서 쓰이는 프로토콜 묶음(4층). OSI의 5·6·7층이 TCP/IP에서는 "응용 계층" 하나로 합쳐진다.
- **프로토콜 vs 계층**: 프로토콜(예: HTTP, TCP)은 "대화 규칙"이고, 계층은 그 규칙이 속하는 "층 번호"다.

**핵심 용어**

- **물리 계층(L1)**: 전기·빛 신호를 실제로 주고받는 층. PDU는 비트(Bit). 장비: 리피터(신호 증폭기), 허브(신호 복사기). 규격: RS-232, X.21
- **데이터링크 계층(L2)**: 같은 네트워크 안에서 프레임(Frame) 단위로 데이터를 전달하고, 오류를 검출하는 층. 장비: 스위치, 브리지. 프로토콜: HDLC, PPP(Point-to-Point Protocol), 이더넷(Ethernet)
- **네트워크 계층(L3)**: 서로 다른 네트워크 사이에서 패킷(Packet)의 경로를 찾아주는 층. 논리 주소(IP 주소)를 사용. 장비: 라우터. 프로토콜: IP, ICMP, ARP(Address Resolution Protocol — IP를 MAC 주소로 변환), OSPF, RIP
- **전송 계층(L4)**: 출발지부터 도착지까지 세그먼트(Segment) 단위로 데이터를 안전하게 전달하는 층. 포트 번호로 프로그램 구분. 프로토콜: TCP(Transmission Control Protocol — 신뢰성 보장), UDP(User Datagram Protocol — 속도 우선)
- **세션 계층(L5)**: 통신 연결(세션)을 열고, 유지하고, 닫는 것을 관리하는 층. PDU: 데이터(Data)
- **표현 계층(L6)**: 데이터의 형식 변환, 암호화, 압축을 담당하는 층. PDU: 데이터(Data). 예: JPEG, MPEG, SSL/TLS
- **응용 계층(L7)**: 사용자가 직접 쓰는 프로그램에 네트워크 기능을 제공하는 층. PDU: 데이터(Data). 프로토콜: HTTP, FTP, SMTP, DNS, SSH

## ✅ 스스로 가르쳐보기

"친구에게 OSI 7계층을 설명한다고 가정하고, 1층(물리)부터 7층(응용)까지 각 층이 무슨 역할을 하고, 어떤 이름(PDU)으로 데이터를 부르는지 말해 보세요."

체크포인트:
- 물리→데이터링크→네트워크→전송 순서로 PDU 이름(비트→프레임→패킷→세그먼트)을 말할 수 있는가?
- 스위치(L2)와 라우터(L3)가 왜 다른 층인지 설명할 수 있는가?
- ARP가 몇 계층이고, 무슨 주소를 무슨 주소로 바꾸는지 말할 수 있는가?

## 🎯 시험 응용

> 각 계층의 PDU 명칭(비트→프레임→패킷→세그먼트→데이터)은 빈칸 채우기로 빈출된다. 계층별 대표 프로토콜과 장비를 매칭하는 문제도 자주 출제된다. 특히 **ARP**(IP→MAC 변환, L3)와 **이더넷**(L2), **TCP/UDP**(L4)의 계층 위치를 정확히 구분해야 한다. 데이터 캡슐화(Encapsulation) 과정에서 각 계층이 헤더를 추가하는 순서도 중요하다.

# 모듈 결합도 6단계

> 🔥 **매회 출제** (priority 3)

![[se-coupling-001.svg]]

## 🌱 왜 배우나

팀 프로젝트에서 한 모듈을 고쳤더니 전혀 상관없어 보이던 다른 모듈이 줄줄이 깨진 경험이 있다면, 그게 바로 결합도가 높다는 증거다. 마치 옷장 서랍들이 서로 못으로 박혀 있어서 한 서랍을 빼려면 옆 서랍까지 같이 빠지는 상황과 같다. 결합도가 높으면 독립적인 수정·테스트·재사용이 불가능해지고, 작은 변경이 대형 장애로 번진다. 그래서 "모듈끼리 얼마나 엮여 있는가"를 단계별로 측정해 낮추려는 결합도 개념이 등장했다.

## 📖 핵심 개념

결합도(Coupling)는 모듈 간의 상호 의존 정도를 나타내며, 낮을수록(약할수록) 좋은 설계다. 결합도가 낮으면 모듈의 독립성이 높아져 유지보수와 재사용이 용이해진다. 6단계를 강→약 순서로 암기하고 각 유형의 정의를 구별하는 것이 핵심이다.

**핵심 용어**

- **Content(내용) 결합도** [최강]: 다른 모듈의 내부 데이터나 코드를 직접 참조·수정 — 최악의 결합
- **Common(공통) 결합도**: 두 모듈이 전역 변수(공통 데이터)를 공유 — 전역 변수 사용
- **External(외부) 결합도**: 외부에서 선언된 변수(외부 데이터 포맷, 프로토콜 등)를 공유 — 공통과 유사하나 외부 환경
- **Control(제어) 결합도**: 한 모듈이 다른 모듈의 제어 흐름(논리적 경로)을 결정하는 파라미터 전달 — 제어 플래그
- **Stamp(스탬프) 결합도**: 모듈 간에 자료 구조(레코드·배열 등)를 파라미터로 전달, 일부만 사용 — 구조체 전달
- **Data(자료) 결합도** [최약]: 모듈 간에 단순 값(스칼라) 파라미터만 전달 — 최선의 결합

## ✅ 이해 확인

1. 결합도 6단계를 강→약 순서로 쓰시오.
   <details><summary>정답</summary>내용 → 공통 → 외부 → 제어 → 스탬프 → 자료 ("내공외제스자"). 자료 결합도가 가장 약하고(이상적) 내용 결합도가 가장 강하다(최악).</details>
2. 한 모듈이 다른 모듈에 true/false 플래그를 넘겨 그 내부 실행 경로를 결정한다면 어떤 결합도인가?
   <details><summary>정답</summary>제어(Control) 결합도. 제어 플래그 파라미터 전달이 핵심 키워드다.</details>
3. Common(공통) 결합도와 Stamp(스탬프) 결합도는 어떻게 구분하는가?
   <details><summary>정답</summary>공통 결합도는 "전역 변수"를 공유하는 것이고, 스탬프 결합도는 "자료 구조(레코드/배열)를 파라미터로 전달"하되 일부만 사용하는 것이다. 공유 수단(전역 vs 파라미터)이 결정적 차이다.</details>

## 🎯 시험 응용

> - **강→약 순서 암기법**: "내공외제스자" (내용-공통-외부-제어-스탬프-자료) > - **2025-1회**: 내용·스탬프·공통 결합도 정의 구분 문제 출제 > - **2024-2회**: 제어 결합도 — 제어 플래그를 파라미터로 전달하는 유형 > - "전역 변수 = 공통 결합도", "제어 플래그 파라미터 = 제어 결합도" 키워드 연결 필수
